## 本仓库的作用
本仓库的作用是配合[草原探险服务器](https://caoyuan.ypshidifu.cn/)的工单系统所独立的一个仓库。<br>
此仓库不定期删除重建，因此如果您想要使用草原探险服务器同款插件或系统，您可关注以下几个项目

| 名字 | url | 作用 |
| --- | --- | --- |
| Sdf1_login | [https://github.com/ypsdf1/sdf1_login](https://github.com/ypsdf1/sdf1_login) | 多功能综合插件 |
| Sdf1_game | [https://github.com/ypsdf1/Sdf1_games](https://github.com/ypsdf1/Sdf1_games) | 游戏插件 |
| CY_beibao | [https://github.com/ypsdf1/CY_beibao](https://github.com/ypsdf1/CY_beibao) | 云背包系统 |
| Sdf1 | [https://github.com/ypsdf1/sdf1_plugn](https://github.com/ypsdf1/sdf1_plugn) | CDK兑换系统 |
